SECCIÓN F: MÉTRICAS EXPLICADAS (Clasificación Multiclase)
================================================================================

**Accuracy:**
- Fórmula: (Predicciones correctas) / Total
- Interpretación: % correcto global
- ⚠️ Engañoso si desbalanceado (80% accuracy pero una clase rara no se detecta)

**Precision (por clase):**
- Fórmula: TP / (TP + FP) para cada clase
- Interpretación: si predijo esa clase, ¿qué tan seguido es correcta?
- Macro-Precision: promedio simple entre clases
- Weighted-Precision: promedio ponderado por frecuencia de clase

**Recall (Sensibilidad por clase):**
- Fórmula: TP / (TP + FN) para cada clase
- Interpretación: de esa clase real, ¿cuántos detectamos?
- Macro-Recall: promedio simple
- Weighted-Recall: promedio ponderado

**F1-Score (por clase):**
- Fórmula: 2 × (Precision × Recall) / (Precision + Recall)
- Macro-F1: promedio simple entre clases → mejor si clases desbalanceadas
- Weighted-F1: promedio ponderado → mejor si clases balanceadas
- ✓ Usa Weighted-F1 para multiclase

**AUC-ROC (One-vs-Rest):**
- Calcula AUC para cada clase vs "resto"
- Ej: Clase 0 vs (1+2+3+...), Clase 1 vs (0+2+3+...), etc.
- Promedio de AUC por clase

**Matriz de Confusión Multiclase:**
- Matriz N × N (N = número de clases)
- [i, j] = cuántas muestras de clase i se predijeron como clase j
- Diagonal = predicciones correctas
- Off-diagonal = errores (confusiones)
- Útil para identificar qué clases se confunden

**Classification Report:**
- Muestra Precision, Recall, F1 para cada clase
- Incluye support (número de muestras por clase)
- Da visibilidad de desempeño desigual

================================================================================
SECCIÓN G: NOTAS FINALES
================================================================================

1. **Desbalance de clases:** Si una clase << otras:
   - Usa Weighted-F1 o Macro-F1, no Accuracy
   - Usa stratified split
   - Usa class_weight='balanced'
   - Considera SMOTE para sobremuestreo

2. **Multiclase vs Multilabel:**
   - Multiclase: 1 muestra → 1 clase (Iris: flor es setosa O versicolor O virginica)
   - Multilabel: 1 muestra → múltiples clases (película: es drama Y acción Y comedia)
   - Esta plantilla es para multiclase

3. **Confusiones comunes:**
   - Matriz de confusión revela qué clases se confunden
   - Ej: Si flores setosa se predice como versicolor, revisa features que diferencian
   - Considera agregar features que separen mejor esas clases

4. **AUC-ROC One-vs-Rest:**
   - Útil pero no es "la mejor" métrica multiclase
   - Weighted-F1 o Macro-F1 son más intuitivas
   - AUC se usa porque es probabilístico y comparable

5. **Interpretabilidad:**
   - Random Forest: fácil ver importancia de features
   - XGBoost: también fácil, pero tree boosting es menos transparente que RF
   - SHAP values si necesitas interpretabilidad avanzada

6. **Predictor con probabilidades:**
   - Siempre muestra probabilidades, no solo clase predicha
   - Si probabilidades son cercanas (ej: 0.33 / 0.33 / 0.33), no confíes
   - Muestra como "Confianza: BAJA" si max_prob < 0.6

7. **Trabajo futuro:**
   - Si una clase tiene F1 bajo, necesita más datos o features mejores
   - Análisis de qué features separan esa clase
   - Técnicas de reducción dimensional (PCA, t-SNE) para visualizar
