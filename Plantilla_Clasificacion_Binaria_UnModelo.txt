SECCIÓN F: NOTAS FINALES
================================================================================

1. **Desbalance:** Si una clase >> otra:
   - Usa stratified split
   - Usa class_weight='balanced'
   - Scoring='roc_auc' es más robusto que 'accuracy'

2. **Threshold:** Default 0.5 pero revisar si es óptimo
   - Threshold alto → menos FP, más FN
   - Threshold bajo → más FP, menos FN

3. **Costo de errores:** FN cuesta más en medicina; FP cuesta más en spam

4. **AUC-ROC:** Métrica robusta para desbalance

5. **Siempre visualiza:** ROC curve, matriz confusión, PR curve

6. **Probabilidades:** Guarda predict_proba, no solo clases
